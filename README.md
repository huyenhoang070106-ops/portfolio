# Hoàng Thị Huyền — Portfolio

Trang web Portfolio cá nhân chuyên nghiệp của **Hoàng Thị Huyền** — Sinh viên Kinh tế Quốc tế Khóa 63, Trường Đại học Ngoại thương (FTU), Trưởng Ban Tổ chức G'CONTEST 2026, Chuyên môn Quản lý Dự án & Phân tích Dữ liệu.

---

## 🌟 Tính năng nổi bật

- **Giao diện Hiện đại & Tối ưu Trải nghiệm**: Thiết kế tối giản, sang trọng phong cách hiện đại với 2 chế độ Dark Mode / Light Mode và song ngữ Anh - Việt (EN / VI).
- **Hero Interactive**: Hiệu ứng nam châm (Magnetic effect) tương tác theo chuyển động chuột cho ảnh đại diện và typography ấn tượng.
- **Marquee Dòng thời gian Hoạt động**: Hiệu ứng cuộn vô tận 2 chiều mượt mà kèm Lightbox tương tác xem chi tiết từng cột mốc sự kiện (G'CONTEST, Học bổng DB Kim Jun Ki, G'TALK, CLB GEC, AIESEC,...).
- **Phần Giới thiệu (About Me)**: Hiệu ứng xuất hiện từng ký tự (Character-by-character scroll animation) đồng bộ theo thao tác cuộn trang.
- **Bento Grid Kỹ năng (Skills)**: Trực quan hóa năng lực chuyên môn Hard Skills (Python, Power BI, Ngoại ngữ, Công cụ số) & Soft Skills (Quản lý dự án, Lãnh đạo, Đàm phán).
- **Thẻ Dự án Tự xếp chồng (Sticky Stacking Cards)**: Hiệu ứng co giãn và xếp đè từng dự án lớn theo chiều sâu khi cuộn chuột.
- **Trình phát Nhạc nền Lofi (Web Audio API)**: Tích hợp bộ tổng hợp âm thanh hợp âm Lofi thư giãn trực tiếp bằng Web Audio API không phụ thuộc file ngoài.
- **Form Liên hệ Tương tác**: Gửi tin nhắn tức thời kèm hiệu ứng pháo hoa (Confetti) và tính năng 1-click sao chép thông tin liên hệ.

## 🛠 Công nghệ sử dụng

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **Hiệu ứng & Chuyển động**: Framer Motion, Canvas Confetti
- **Biểu tượng**: Lucide React
- **Bộ công cụ xây dựng (Build tool)**: Vite

## 🚀 Hướng dẫn cài đặt và chạy cục bộ (Run Locally)

### Yêu cầu
- Đã cài đặt **Node.js** (phiên bản 18 trở lên khuyến nghị)

### Các bước thực hiện

1. **Cài đặt thư viện phụ thuộc:**
   ```bash
   npm install
   ```

2. **Chạy máy chủ phát triển (Development server):**
   ```bash
   npm run dev
   ```
   Sau đó mở trình duyệt và truy cập `http://localhost:3000` (hoặc cổng hiển thị trên terminal).

3. **Đóng gói sản phẩm (Build for Production):**
   ```bash
   npm run build
   ```

4. **Xem trước bản build (Preview):**
   ```bash
   npm run preview
   ```
